# P2 A2 实验计划

2026-09-27，训练前记录。A1 没有明确整体收益，本轮仍以原扩充模型为参考，只改变 close_mosaic：0 → 10。

固定配方：同一官方 YOLOv8n 初始化权重、394 train / 114 val、128 输入、50 轮、batch=8、CPU 4 线程、seed=20260926、AdamW、lr0=0.001、warmup_bias_lr=0.1。第 1～40 轮 Mosaic 概率为 1，第 41～50 轮为 0。其他几何增强仍然存在，关闭 Mosaic 不等于关闭全部增强；当前 MixUp、CutMix、CopyPaste 本来为 0。

训练入口新增可选参数，省略时仍为原项目默认 0。每轮首个批次开始时读取实际增强图并记录 Mosaic 概率，此时框架已经执行本轮增强切换及数据加载器重置。观察器不执行增强、不额外取样，不消耗随机数。

训练后核对配置仅有目标参数与输出路径差异，审核文件与初始化一致；要求 50 轮增强观察完整，并比较前 40 轮所有已保存损失、指标和学习率（排除墙钟时间）是否与参考一致。若介入前已出现差异，先调查，不直接宣称单变量收益。

输出目录 `experiments/p2_a2_close_mosaic/`，原模型、A1 及 P3 结果保留。随后在同一 109 张开发图上评估 AP、固定工作点（conf=0.25 / NMS IoU=0.45 / 匹配 IoU=0.5）、小目标分组、误检负样本、逐目标补检/丢失及代表图片。测试 16 张只核对完整性，不推理或选择阈值。

首要判断为整体收益与误检取舍，不因单种子 mAP 小幅上涨自动替换模型。若 A2 无明确收益，停止在此处盲调，转向匹配的较高分辨率训练。

运行：`python -m tools.run_a2_experiment --output experiments/p2_a2_close_mosaic`。
