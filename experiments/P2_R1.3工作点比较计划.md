# P2 R1.3 工作点比较训练前计划

2026-09-27。对应 [R1 交接](../docs/P2_R1交接.md)第 3 节。在冻结候选(R1 320 模型,`p2_r1_resolution320_retry1/train/fit/weights/best.pt`)上比较少量**预先声明**的置信度/NMS 工作点;写本计划时未查看任何扫点结果。

## 预声明方案(共 5 个,不追加)

| 方案 | conf | NMS IoU | 动机 |
|---|---:|---:|---|
| S0(现行) | 0.25 | 0.45 | 现行固定工作点,作为参考 |
| S1 | 0.35 | 0.45 | 提高置信度,观察误检下降与召回代价 |
| S2 | 0.45 | 0.45 | 进一步提高置信度 |
| S3 | 0.25 | 0.30 | 收紧 NMS,针对台账中 4 个重复框型新增误检 |
| S4 | 0.35 | 0.30 | 两个方向的组合 |

依据:R1.2 台账显示范围失配型误检(18/36)不会被阈值消除,重复框型(4/36)可被更紧 NMS 缓解,背景误认(8/36)部分对置信度敏感;故只在这两个方向取小网格。

## 执行与报告

- 每个方案都用 `runtime.vision` **重新推理** 109 张共同开发图(conf 与 iou 都真实传入),不做任何事后过滤冒充;逐方案 `training.error_analysis.analyze` 输出每类 TP/FP/FN/召回率、精确率与负样本图片误检数。
- 不修改匹配规则(IoU=0.5)、不改标签、不触碰 16 张 test。比较结果只用于工作点讨论,不自动变更默认配置;是否采用新工作点在简报中单独说明。
- 每类阈值方案(如明火单独提高阈值)暂不纳入;待本网格结果与人工台账抽查完成后再评估是否需要。
- 工具:`python -m tools.run_r13_working_points --weights experiments/p2_r1_resolution320_retry1/train/fit/weights/best.pt --imgsz 320 --output experiments/p2_r13_working_points`。
