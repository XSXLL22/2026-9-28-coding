## 节点结果

### P4.0 量化合同 v1.2 冻结

[定点格式说明](../docs/定点格式说明.md) + [quantization_contract.json](../configs/quantization_contract.json)。修订链:1.0 → 1.1(P4.1 结构审计修正 BN 折叠公式、整数边界移到检测头原始分支输出、补 add/concat/权重舍入规则)→ 1.2(浮点对拍发现 maxpool 边界必须是 -inf 语义,补零会污染全负窗口)。核心约定:W8A8 对称零点 0、权重按输出通道/激活按层、int32 累加逐层校核、乘子 ∈[2³⁰,2³¹)+算术右移 round-half-up、SiLU 逐层 256 项查表、算子三类分派(PL_V1 / PS_INT / PS_FLOAT)、整数覆盖终点为检测头 6 个原始输出张量(Ultralytics 的 DFL 是 softmax 之后做固定卷积,属 PS_FLOAT)。

### P4.1 BN 折叠与导出器

`training/exporter.py`:符号图追踪(95 节点、63 卷积全部落入 PL_V1 支持的 3×3/1×1 s1/s2、57 处 SiLU 列入学生模型替换清单、6 处骨干残差 add、6 个整数域终点输出)。折叠核验:执行器输出 vs 原始框架逐模块钩子对比 72 节点,**最大偏差 4.2e-05**(容差 1e-4)。9 项单元测试。[报告](p4_export/report.json)。

### P4.2 PTQ 校准

`training/calibrate.py`:train 内冻结 64 张子集(seed 20260928,清单含哈希),76 层(63 卷积 + 13 concat)直方图校准;逐层规则选择(估计 L2 误差较小者):max_abs 70 层、percentile 99.9% 6 层;p99.9 饱和率最大 0.1%。权重量化最坏 L2 = 0.493(整网 63 层)。109 张开发图未参与定 scale。[报告](p4_ptq/report.json)。

### 模型包(P4PKB01)

`training/export/p4_baseline128_v1/model_pack.bin`(2.96 MiB):127 节点(63 卷积 + 32 requant + 32 数据搬移),57 张 SiLU 查表,逐层乘子/移位/偏置与累加校核(最坏占 int31 的 1.7%),附 JSON 清单与哈希。

### P4.3/P4.4/P4.5 双参考与 golden vectors

- Python 参考 `reference/python/`(numpy 整数域执行);C 参考 `reference/c/int_reference.c`(gcc 13.2.0 `-std=c11 -O2 -Wall -Wextra` 零警告,可交叉编译子集)。
- 15 个 golden vectors:正常/边界/负数/饱和×2/随机×2/尾通道微型包(cin=5)/真实图×8。每个向量 104 个逐节点期望输出(微型包 1 个)。
- **验收:P4.5 验证器 [p4_golden_verification/report.json](p4_golden_verification/report.json) 显示 15/15 向量、每向量 104 节点,Python 与 C 全部逐位一致。**
- 调试中发现并修复的 C 缺陷(int32 位模式 memcpy 未做 4→8 位转换;maxpool/upsample 输出通道步长少乘 w_out)——两侧不一致即为验证器捕获,符合设计意图。

### P4.6 资源与带宽(估算)

[报告](p4_resource/report.json):**161.65 MMAC/帧**、int8 权重 2930 KiB、逐层激活读写 1324 KiB/帧;DDR 流量下界 1324 / 上界 4254 KiB/帧。Zynq-7010/7020 背景(220 DSP @125 MHz):峰值 27.5 GMAC/s → 帧率上界 170 FPS;实际并行度/频率属 P5 综合范畴,本表只用于排除明显不可行方案。

### P4.7 PTQ 精度评估与 QAT 决策门

[报告](p4_ptq_eval/report.json)。共享解码器(已对框架自身头解码验证:框差 2.7e-4 px、分数差 2e-7)+ 池化 AP50,同一口径跑 FP32 执行器与整数参考:

| 路径 | smoke AP50 | fire AP50 | mAP50 |
|---|---:|---:|---:|
| FP32(折叠) | 21.86% | 0.97% | 11.42% |
| INT8(W8A8 PTQ) | 13.19% | 1.59% | 7.39% |

**mAP50 下降 4.02 个百分点,超出 -3pp 探索目标 → QAT 决策门触发。** 工作点(conf=0.25、NMS 0.7、匹配 0.5)int8:smoke TP13/FP31、fire TP4/FP28;负样本有预测图片 5/43(FP32 为 10/43)。

## 结论与限制

- 绝对 AP 值与本库 mAP 口径不可比(自研解码器 + 池化 AP),**只有同口径 delta 有意义**;-4.02pp 表示纯 PTQ 不可接受,按预声明只产出 QAT 提案供用户决策,未自动启动。
- 明火 AP50 本来就极低(公开数据小样本 + 0.97%),int8 后其绝对损失(0.62pp)小于烟雾(8.7pp)——低分亮度目标的量化敏感度差异应在 QAT 设计中验证。
- 默认模型与运行链路完全未变(仍是 FP32 128 基线);P3、P2 未受影响。
- 16 张 test 未使用;现实采集、硬件采购仍暂缓。

## QAT 提案草案(供决策,未启动)

若决定推进:QAT 需要训练循环改造(伪量化节点插入 BN 折叠后的卷积、SiLU 查表近似的前向/直通估计器反向),以第 41 轮后的收敛权重为起点重训 ≤10 轮观察恢复幅度;预算约 2–4 个会话。备选:仅对最敏感的浅层(model.0/model.1/各 C2f cv1)用 W8A16 激活,改动小但带宽翻倍,需重新核算 P4.6。
