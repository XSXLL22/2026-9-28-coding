# P2 R1 训练前计划

2026-09-27。检验原先 128 输入是否限制小目标识别。训练与评估同步改为 320；仅供软件诊断，硬件目标和运行默认仍为 128。

- 原始 YOLOv8n 初始化、394 train / 114 val、50 轮、batch=8、CPU 4 线程、seed=20260926、AdamW、lr0=0.001、warmup_bias_lr=0.1、close_mosaic=0。
- 逐项核对实际训练参数，只允许 imgsz 和输出目录变化。数据、初始化与原模型哈希校验必须通过；每轮观察 Mosaic 保持启用。
- 共同开发集 109 张，工作点 conf=0.25、NMS IoU=0.45、同类匹配 IoU=0.5。16 张 test 不推理。
- 小目标分组始终按 128 参考尺度计算；比较入口必须显式允许跨尺寸，并核对 NMS、目标几何和分组。旧参考复核页从既有预测重新生成，不重新推理或修改历史产物。
- 同时报告分类型 AP、TP/FP/FN、小目标检出、负样本误检及逐图补检/丢失；不因单个总指标改善自动推广模型。
- 保存训练与运行耗时，但不推断 FPGA 性能。单种子、反复使用开发集、来源场景未知仍限制泛化结论。

入口：`python -m tools.run_r1_experiment --output experiments/p2_r1_resolution320`。失败保留日志和产物，不覆盖后伪装为首次成功。

执行记录：首次运行在第 1 轮保存权重时遇到 Polars CPU 架构检测错误；原目录保留。运行环境缺少 PROCESSOR_ARCHITECTURE，已增加从 Windows 系统接口恢复缺失架构的处理，不绕过 CPU 检查。65 项回归测试通过后，以 `--output experiments/p2_r1_resolution320_retry1` 从同一初始化重跑；首轮指标、损失和学习率已与首次运行核对一致（除耗时）。最终结果以 retry1 总报告及后续简报为准。
