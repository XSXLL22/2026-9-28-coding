# P2 R1.1 收益重复验证简报

2026-09-28。按[训练前计划](P2_R1.1种子重复实验计划.md)完成第二个固定种子 seed=20260927 下的 128 与 320 配对训练、共同开发验证、固定工作点推理及三组逐图对照。冻结 R1 工具未修改；R1.1 使用新入口 `tools.run_r11_paired_experiment`，种子显式给出。首次运行在训练后因入口命令构造错误中断，原目录保留，retry1 完整重跑且两臂首轮已保存数值与失败运行一致（排除耗时）。

## 实验控制与核验

两臂同种子、同官方 YOLOv8n 初始化、同 394/114 数据、50 轮、batch=8、CPU 4 线程、AdamW、lr0=0.001、warmup_bias_lr=0.1、close_mosaic=0。实际 `fit/args.yaml` 逐项核对：128 臂相对冻结基线仅差输出目录与 seed；320 臂相对 128 臂仅差 imgsz。两臂数据审核与冻结基线完全相同，50 轮增强观察确认 Mosaic 概率均为 1。

- 新种子 128 臂权重 SHA256：`67628a5a4927098830f5ced796ba7f1f2447b1fdcbf62f6262cfbfc59ef47534`，best 对应轮次：34（指标匹配推断）。
- 新种子 320 臂权重 SHA256：`7a84d1a82df2f13010182a4f3c5da5f789d2600246227eaa487e76f394bf2392`，best 对应轮次：47（指标匹配推断）。

## 同尺寸种子波动

- 128：旧种子 vs 新种子 50 → 54 TP，30 → 47 FP；补检 11、丢失 7。
- 320：旧种子 vs 新种子 71 → 66 TP，48 → 48 FP；补检 14、丢失 19。

同尺寸的种子波动是解读 320 收益时的本底噪声，不能把小于该波动幅度的差异当作稳定收益。

## 结论与限制

- 两个种子的配对方向是否一致见上表；两个种子仍不能宣称统计稳定性，也不据此自动推广 320 为默认。
- 后续仍按 [R1 交接](../docs/P2_R1交接.md)：R1.2 新增误检分类、R1.3 工作点比较，之后才考虑 P3 对接与 ROI/切片。
- 16 张 test 继续保留不推理；无硬件采购、真实采集或 P3 修改；耗时为本机软件数据，不代表 FPGA 性能。

## 人工解读（本轮补充）

- **收益方向在第二个种子重现**：mAP50 增益 +13.62 → +10.72 个百分点，幅度变小但方向一致；mAP50:95 同样为正。小目标收益重现（fire lt8 检出 2 → 12、8to16 5 → 11），R1"低分辨率限制小目标"的判断得到第二次支持。
- **FP 代价并非常数**：旧种子下 320 使框 FP 30 → 48（+18）；新种子下 47 → 48（+1），且净检出 54 → 66。R1.2 台账中的范围失配型误检在新种子 320 上依然存在（FP 总量近似），但"320 必然大幅增加误检"的说法不成立，误检代价随种子波动明显。
- **种子本底噪声不可忽略**：同为 128 输入，两种子 FP 相差 30 ↔ 47；解读任何小于该量级的差异都不可靠。两个种子远不足以给出稳定性区间。
- smoke ge16 检出 35 → 31、smoke TP 35 → 34：新种子 320 在较大烟雾上略差于其 128 臂，收益主要集中在明火；换默认权重时不能只看总 mAP。
