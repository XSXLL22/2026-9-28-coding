# P3 离线融合简报

2026-09-27。状态：完成首版离线模拟原型与 P2 接口联通，未完成整个 P3，更不代表现场报警验收。

## 节点 P3.1：数据合同与时间检查

已实现视觉、环境温度两条输入流的校验：节点、会话、时钟、记录身份、采样/可用时间、有效性、单位、模型来源、支持类别和原图框。输入必须明确为 simulation；环境温度缺失不能填写 0，不能冒充红外表面温度或烟雾浓度。

完全相同的重复 ID 去重，冲突 ID 报错。晚到的旧采样及重复视觉帧不会覆盖新数据；未到可用时刻的记录不会参与风险判断。模型、运行来源或传感器身份在同一会话发生改变会报错。

## 节点 P3.2：健康状态、升级、保持和恢复

已实现 NORMAL / ATTENTION / WARNING / ALARM，并独立输出 OK / DEGRADED / UNAVAILABLE 及评估有效性。首次缺少充分观察时风险为 null。强视觉证据在温度缺失时仍可升级，但整体评估会标记受限。

持续时间由新观测推进，不能靠重复 tick 或重复记录累积。断流、过期和无效输入不能解除已知风险；恢复需要视觉、温度均新鲜对齐并持续满足较低阈值。保留风险时仍保存最初建立该风险的证据 ID，避免因最新证据过期而丢失原因。

当前默认配置中的数字**全部为模拟示例，未标定**。作用范围为全图；没有落叶、物理烟雾传感器、火焰模块、红外测温或 ROI 距离规则。

## 节点 P3.3：回放及实际 P2 对接

最终采用 [p3_simulation_release1](p3_simulation_release1/report.json) 的 8 个模拟场景，每个重复两次且输出相同。早期 `p3_simulation_v1`、`p3_simulation_v2`、`p3_simulation_final` 保留为实现过程快照；最终检查补充了明确相机故障不被重复帧过滤的处理，以 release1 作为当前版本验证依据。

| 场景 | 实际观察到的行为 |
|---|---|
| 持续正常后断流 | 3000 ms 确认 NORMAL；5000 ms 起 UNAVAILABLE、评估无效，保留最后已知状态 |
| 强视觉单源 | 500 ms ATTENTION，1000 ms ALARM；温度缺失不阻止升级，断流不解除 ALARM |
| 单张高分火焰 | 没有累积持续时间，不升级为 ALARM |
| 烟雾与温度组合 | 1000 ms ALARM，输入齐备时评估有效 |
| 持续正常恢复 | 已有 ALARM 保持至 4500 ms，满足连续 3000 ms 恢复证据后 NORMAL |
| 重复同一记录 | 去重，不形成持续异常 |
| 延迟到达的未来记录 | 提前不消费，到达时已过期则不作为有效证据 |
| 晚到的旧采样 | 忽略旧采样，不覆盖更新的视觉观察 |

这些时间只是配置与合成输入下的状态机输出，**不是现实火灾发现延迟**。

已用既有三帧静态图构造的视频输出完成 P2→适配器→融合入口验证。三帧指定 0/200/400 ms 的模拟采样时间及 100 ms 模拟延迟，再加入三条模拟温度输入，共 6 条输入、9 个 tick。

- 两次命令行运行的事件及状态文件逐字节一致。
- 验证未来信息隔离、最终过期状态及不能误确认正常。
- 单独输入错误 clock_id，进程非零退出，报告明确 `status=failed`。这是预期拒绝测试，不是隐藏的运行故障，日志保存在验证目录。
- P2 原结果过滤阈值是 0.25，高于恢复规则的 0.15。融合明确标记 `vision:floor_above_recovery_threshold`，不将高阈值下的空输出解释为满足恢复条件。

证据：[视觉适配报告](p3_p2_bridge_v1/report.json)、[显式模拟时间清单](p3_bridge_timeline.json)、[最终接口核验](p3_bridge_verification_release1/verification.json)。早期 `p3_bridge_verification_v1`、`p3_bridge_verification_final` 是中间快照。

## 测试和边界

本轮最终运行 `python -m unittest discover -s tests -v`：**55 项通过**，包含原有 28 项和新增 27 项诊断、融合与适配测试。覆盖重复帧、时钟、单位、NaN、未知类别、冲突记录、乱序、过期、迟到间隔、阈值过滤、四级状态和恢复；明确的相机故障即使沿用上一帧编号也不能被去重逻辑忽略。

本轮没有训练、部署、购买设备或采集现实数据。模拟阈值不证明报警可靠；固定全图烟雾与温度同节点不等于已建立物理空间对应；不同图片拼接的视频不支持事件级误报率或召回结论。预热和推理超时可以通过无效输入及过期表达，但尚无真实设备驱动主动生成这些状态。

下一步可推进：P2 的 A1 单变量训练；P3 的公开连续视频协议与事件标注、温湿度等额外输入类型及明确的空间对应。应先稳定软件能力与评估，再进入硬件实现。
