# P2 扩充数据与同集对照操作说明

本流程使用项目内 Python 3.12 环境；所有命令从工程根目录运行。原始 80 张试验保持不变，扩充数据独立存放。输出目录存在时，准备/训练/评估工具拒绝覆盖；下载器仅允许相同样本数量续传。

## 下载与准备

```powershell
.\.venv\Scripts\python.exe tools/fetch_public_pilot.py --train 512 --val 128 --test 16 --output datasets/public_expanded_v1 --reuse datasets/public_pilot
.\.venv\Scripts\python.exe tools/prepare_expanded_dataset.py --source datasets/public_expanded_v1 --output datasets/public_expanded_v1_prepared
.\.venv\Scripts\python.exe tools/prepare_comparison_split.py --prepared datasets/public_expanded_v1_prepared --old-audit experiments/p2_pilot_train_50epochs/data_audit.json --output datasets/public_expanded_comparison
```

工作区已有完整结果时，不再重复执行准备命令。下载复用文件须匹配已有清单哈希；新下载使用临时文件再改名，避免中断文件冒充完成文件。图片解码、原始文件哈希、类别、坐标边界、EXIF 方向和集合重复都需通过检查。

清洗只将合法有限框裁剪到可见图像范围；类编号、非有限坐标、异常宽高和 EXIF 旋转均不静默修正。`preparation.json` 保存全部来源、变化、相似关系、隔离记录和最终统计，`audit.json` 保存最终图片/标签哈希。

相似筛查：图片字节/解码像素完全重复，或去掉 DC 的 63 位 pHash 汉明距离≤6。按连通分量保守隔离，test 优先，随后一个 val，最后一个 train。原文件不删除、不移动到其他划分。测试图仅做完整性/相似性检查，不展示、不推理、不选模型。这个阈值是筛查规则，不能视为真实视频身份判别器，也不保证所有相似场景都被发现。

## 训练与公平对照

```powershell
if (-not $env:PROCESSOR_ARCHITECTURE) {
    $env:PROCESSOR_ARCHITECTURE = [System.Environment]::GetEnvironmentVariable('PROCESSOR_ARCHITECTURE', 'Machine')
}
.\.venv\Scripts\python.exe -m training.baseline train --data datasets/public_expanded_v1_prepared/data.yaml --weights models/yolov8n.pt --output experiments/new_expanded_training --epochs 50 --batch 8 --device cpu
```

实际已运行模型的报告目录见实测报告。训练使用 394 张，验证选权重使用 114 张。为比较已存在的旧模型，共同验证集进一步排除与其旧训练图处于同一筛查分组的 5 张，最终共同评估 109 张。共同集合仍然用于开发验证，不能称为独立最终测试。

对旧、新两个权重分别执行下面的流程；替换权重与独立输出目录，其他参数保持一致：

```powershell
.\.venv\Scripts\python.exe -m training.baseline evaluate --data datasets/public_expanded_comparison/data.yaml --weights <模型路径> --output <评估输出目录> --eval-sizes 128 --device cpu
.\.venv\Scripts\python.exe -m runtime.vision --weights <模型路径> --source datasets/public_expanded_comparison/images/val --output <推理输出目录> --imgsz 128 --device cpu
.\.venv\Scripts\python.exe tools/build_failure_review.py --run <推理输出目录> --audit datasets/public_expanded_comparison/audit.json --labels datasets/public_expanded_comparison/labels/val --output <逐图复核目录>
.\.venv\Scripts\python.exe tools/compare_vision_runs.py --old-review <旧复核目录>/review.json --new-review <新复核目录>/review.json --output <对照结果.json>
```

最后一步逐图核对图片、标签、输入尺寸、置信度与匹配阈值，并记录每个标注框的“旧漏检→新检出”和“旧检出→新漏检”，不能只看总数。图片级负样本误检与目标框 FP 分开统计。AP 的库内工作点不同于固定阈值推理，报告中需分开呈现。

## 保留的限制

真实来源视频/地点分组未补齐；相似筛查存在漏检与误杀。训练样本数量、数据组成和每轮步数同时变化，不能声称完成了单变量数据量消融。只用一个随机种子、一次训练，暂不估计跨种子方差。没有新增校园采集、落叶模型、GPU 或 FPGA 结果。
