# 校园火险多源感知预警系统阶段任务清单

版本：v0.3，2026-09-27

本清单用于安排后续工作。当前没有 FPGA、摄像头和传感器，P0-P5 的软件与仿真工作可以先在电脑上推进；P6-P7 依赖实际板卡和器件。2026-09-26 根据用户要求暂缓现实采集，P2 可先使用公开烟火数据推进；阶段完成仍须满足原验收条件，不能把小样本试验等同于校园三类检测完成。

状态约定：`未开始`、`进行中`、`已完成`、`阻塞`。状态以各阶段的产物和验收条件为准。

## 阶段总览

| 阶段 | 重点 | 硬件要求 | 主要产物 |
|---|---|---|---|
| P0 | 需求、环境和目录冻结 | 无 | 需求基线、工具清单、工程骨架 |
| P1 | 数据和标注准备 | 无 | 数据集、标注规范、数据划分 |
| P2 | 电脑端视觉基线 | 无 | 浮点模型、评估报告、检测输出 |
| P3 | 多源融合软件 | 无，可用模拟数据 | 融合模块、状态机、事件日志 |
| P4 | 量化和整数参考 | 无 | PTQ/QAT 模型、Python/C 参考、golden vectors |
| P5 | FPGA 算子 RTL 仿真 | 无，可选综合工具 | RTL、测试台、逐位对拍、资源估算 |
| P6 | 板卡和传感器 bring-up | 需要 | 板卡测试、接口驱动、传感器标定 |
| P7 | 上板部署和系统实验 | 需要 | 端到端系统、性能报告、论文数据 |

## 当前建议的实际操作顺序

先完成 P0 中的环境检查和配置文件，再做 P1 的数据规范；随后实现 P2 的电脑端视觉基线和 P3 的传感器模拟回放。P2/P3 稳定后立即开始 P4 的整数参考，不必等待硬件。P5 的 RTL 从一个 3×3 卷积模块开始，逐位对拍通过后再扩展。最后依据 P4/P5 的资源估算筛选二手板卡，进入 P6。

## 每次提交或阶段结束时必须保存

- 使用的配置文件和版本号；
- 输入数据或数据清单；
- 模型权重或导出文件；
- 运行命令和环境信息；
- 输出日志和指标；
- 未通过的测试及原因；
- 下一阶段的进入条件。

不要把“代码能运行”“仿真通过”“综合成功”和“板上实时运行”混为同一个完成状态。
