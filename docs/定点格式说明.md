# 定点格式说明(P4 量化合同 v1)

版本:p4-contract-1.3,2026-09-28 冻结。1.3 修订(E1 数值域复核,不改变任何已发包数值):① 累加界改为逐通道 B[o] = |qb[o]| + 128·Σ|qw[o,:]|——激活域 [-128,127] 故 |qx| 可达 128,旧的『乘 127 乘积式』不保守,且 int8 的 abs(-128) 会静默溢出回 -128,必须先展宽 int64 再取绝对值;② 累加越界由打包函数真实抛错,不再依赖调用点注释;③ 移位范围显式限定 n ∈ [0, 62]:n = 0 合法(y = t),n < 0(scale ≥ 2³⁰)与 n > 62 在打包时拒绝——C/RTL 对负移位是未定义行为;④ 重量化中间位宽证明 |acc·M + half| ≤ (2³¹−1)² + 2⁶¹ < 2⁶³,打包时以精确整数执行该检查。1.2 修订:P4.1 浮点对拍(折叠+图追踪 vs 原框架,最大偏差 0.134 集中在 SPPF 第一个池化)发现 max-pool 边界填充必须是标准 **-inf 语义**(补零会污染全负边界窗口),C 参考与将来 RTL 取 max 时必须忽略填充位置。1.1 修订:P4.1 对真实 checkpoint 的结构审计发现三处错误,在任何模型包/向量生成前修正——① BN 折叠偏置公式补上减均值项;② 整数覆盖终点改为检测头 cv2/cv3 最后一层卷积的 6 个原始输出张量(Ultralytics 的 DFL 是 softmax 之后才做固定 1×1 卷积,故 DFL/softmax/解码均为 PS_FLOAT);③ 补充逐元素 add(残差)、concat 输入重量化、scale 保持类算子与权重舍入规则。机器可读版:[configs/quantization_contract.json](../configs/quantization_contract.json)(两份同时生效,以 JSON 的 `contract_version` 为准;任何修改都必须同步升版本并重生成模型包与 golden vectors)。本文给出每条规则的定义、推导方式与可复算示例,目标是"第三方按文档能独立重算任一层输出"。

## 1 数值域与张量格式

| 项目 | 冻结值 |
|---|---|
| 输入通道顺序 | RGB(与冻结的 letterbox 预处理一致,导出器记录原图→网络输入全链参数) |
| 输入量化 | `x = pixel/255 ∈ [0,1]`,`q = round_half_up(x·127)`,int8 存 0..127,`sx = 1/127`,零点 0 |
| 激活布局 | 主存 NHWC;逐层记录逻辑尺寸;硬件要求时尾通道补 0 对齐 |
| 权重布局 | OIHW,int8,按输出通道量化,零点 0 |
| 偏置 | int32,`qb[o] = round_half_up(b_folded[o] / (sx·sw[o]))`,其尺度恰为 `sx·sw[o]` |

输入量化说明:对称、零点 0 的合同作用在非负的 [0,1] 像素上只用到 int8 正半程(0..127),这是已知且接受的取舍;不引入非对称零点,保证全部后续算术共享同一套乘子/移位规则。

## 2 Conv+BN 折叠(先折叠,后量化)

顺序冻结:float32 域先折叠 BN,再做权重/偏置量化;激活函数不折叠。

```
w_fold = w · γ / sqrt(var + eps)        eps = 1e-5(训练时值,导出器从 checkpoint 读取)
b_fold = β + (b0 − μ) · γ / sqrt(var + eps)
```

权重舍入:`qw[o] = sat_int8(round_half_up(w_fold[o] / sw[o]))`,与重量化同一条舍入规则;幅值最大的权重恰好映射到 ±127。

Ultralytics 的 `Conv` 模块是 Conv2d+BN+SiLU 的组合,折叠作用于其中 Conv2d 与 BN 两个子层,SiLU 保留为独立整数算子(见 §5)。折叠前后模型在 float 域逐点输出差应 ≤1e-4(由导出器在抽样图像上实测并记录;这是"折叠正确性"验收,不是量化误差)。

## 3 量化尺度

**权重(按输出通道)**:`sw[o] = max(|w_fold[o]|) / 127`;全零通道取 `sw[o] = 1e-12`,`qw` 全零。

**激活(按层张量)**:`sx = clip_abs / 127`。合同只冻结允许的两种规则及其计算方法:

- `max_abs`:clip_abs = 校准集上该层绝对值最大值;
- `percentile_abs`:clip_abs = 校准集该层 |激活| 的 p 分位数(p 记录于模型包,建议 99.9)。

用哪种规则、每个层的具体数值,属于**模型包校准产物**(P4.2 从冻结的 64 张 train 子集计算),不属于合同;109 张开发图绝不参与定 scale。

## 4 重量化(乘子 + 移位)

卷积整数定义(与实现架构 §5 一致):

```
acc(int32) = Σ(qx · qw) + qb          # Σ 先于偏置,溢出上界按 §6 校核
real scale  r = sx · sw[o] / sy
近似        r ≈ M · 2^-n,M = round_half_up(r · 2^n) ∈ [2^30, 2^31)
输出        y = sat_int8( round_half_up( (acc · M) / 2^n ) )
激活        在饱和之后施加(ReLU/SiLU 都作用于 int8)
```

中间乘法在 int64:`t = (acc + qb) · M` 可达 63 位,合同要求实现使用 int64/足够位宽,不得默认截断。

**舍入规则(对一切符号统一)**:`round_half_up` 即

```
n ≥ 1: y = (t + (1 << (n-1))) >> n     # >> 为算术右移,负数同样处理
n = 0: y = t
```

示例(n = 2,即除以 4,加 2 后算术右移):

| t | 计算 | y | 与真实 t/4 比较 |
|---:|---|---:|---|
| 9 | (9+2)>>2 | 2 | 2.25 → 2 |
| 7 | (7+2)>>2 | 2 | 1.75 → 2(0.5 入上) |
| −5 | (−5+2)>>2 | −1 | −1.25 → −1 |
| −6 | (−6+2)>>2 | −1 | −1.5 → −1(0.5 入上,即向 +∞) |
| −7 | (−7+2)>>2 | −2 | −1.75 → −2 |

即负数半路一律向 +∞ 入,不为负数单独定义"四舍五入远离零";Python 与 C 与将来的 RTL 都必须逐位复现该表。

**饱和**:int8 范围 [−128, 127],越界截断;饱和发生在舍入之后、激活之前。

## 5 逐元素与数据搬移算子(整数域)

| 算子 | 整数定义 | 位Exact 性质 |
|---|---|---|
| ReLU | `max(0, q)` | 精确 |
| SiLU | 256 项查表:`out = quantize_fp(silu_fp(v·sy), sy)`,v 为输入 int8;运行时仅查表,无算术 | 表由合同确定性生成,入模型包 |
| MaxPool 5×5 s1 p2(SPPF) | 整数取 max,边界填充为标准 **−inf 语义**(填充位置不参与取 max;补零会污染全负窗口) | 精确 |
| Upsample nearest ×2 | 索引复制 | 精确 |
| Concat / Split | Split(scale 保持)精确;Concat 的输出 scale 是校准产物,**每个输入先重量化到该 scale** 再重定址 | 精确 |
| Add(残差) | 输出 scale = 第一操作数(C2f 中继续向后传播的 pass-through)的 scale;第二操作数先重量化到该 scale,再 `sat_int8(a + b')` | 重量化遵循 §4 |

SiLU 采用查表而非分段多项式,原因:多项式近似的每一步舍入都要写进合同并逐位复现,成本高于 256 项查表且更容易在 C/RTL 之间出错;查表的代价(逐层 256 项)在模型包体积中可忽略。

## 6 累加上界校核(int32 不默认安全)

对每层每输出通道(1.3 起):

```
B[o] = |qb[o]| + 128 · Σ(|qw[o,:]|)      # 128 = max|qx|,激活域 [-128,127]
bound = max_o B[o]
```

和式界逐通道计算且严格覆盖全部合法输入(|acc| ≤ Σ|qx·qw| + |qb| ≤ 128·Σ|qw| + |qb|);首层输入域是 [0,127],共享 128 的保守界。权重必须先展宽为 int64 再取绝对值——int8 的 `abs(-128)` 会静默溢出回 -128。`bound > 2^31 − 1` 的层:打包函数**直接抛错**,要求登记逐层例外(提高累加位宽或分组累加);不允许静默假设 int32 够用。

重量化中间位宽(1.3 起为证明项):|acc·M + half| ≤ (2³¹−1)² + 2⁶¹ < 2⁶³,故 int64 中间量充分;打包时以 Python 精确整数执行该检查。移位范围 n ∈ [0,62] 显式限定,n = 0 即 y = t;n < 0 与 n > 62 在打包时拒绝。

## 7 算子分派与整数边界

- `PL_V1`:3×3/1×1 卷积(stride 1/2)、ReLU、重量化——将来进 PL。
- `PS_INT`:SiLU 查表、MaxPool、Upsample、Concat/Split——整数参考内逐位实现,当前在处理器执行。
- `PS_FLOAT`:DFL 固定卷积、softmax、期望解码、sigmoid、框解码、NMS、坐标还原——浮点后处理。

整数合同的覆盖终点:**detect 头 cv2/cv3 每尺度最后一层 1×1 卷积的 6 个 int8 原始输出张量**。注意 Ultralytics 的 `DFL` 模块先对 16 个 bin 做 softmax、再做固定 1×1 卷积,softmax 属浮点后处理,因此 DFL 卷积整体不进入整数域。其后全部为 PS_FLOAT,任何"整网 int8"的表述以此边界为准。导出器必须给网络中每个模块标记且仅标记一个类别,未分类算子视为导出失败;当前 YOLOv8n 的 SiLU 全部落入 PS_INT,并进入"学生模型须替换为 ReLU"清单(决策属后续训练,不在 P4)。

## 8 模型包与版本

模型包必含:`model_id`、`contract_version`、`format_version`、逐层描述符(类型/尺寸/通道/stride/padding/量化表/乘子移位)、int8 权重、SiLU 查表、累加校核结果、校验值、golden vector 清单引用。同合同同输入必须生成逐字节相同的包;导出器记录自身源码哈希。改任何规则 → 升 `contract_version` → 旧包按其记录的版本继续有效。

## 9 与验收的对应

- P4 验收"每层定点规则可独立解释和复现":按本文 §2–§6 应能手工重算任一层;golden vectors(P4.5)给出每条规则分支的实例(负数舍入、饱和、尾通道、边界)。
- P5 的 RTL 对拍对象即本文定义的整数行为,RTL 修改不得先于合同修订。
