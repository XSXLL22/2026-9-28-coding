## 2 范围与模型身份

- 量化对象:冻结 128 基线(`c93676b3…`)。R1/新种子 320 候选**不量化**(软件诊断身份不变);若将来 320 晋升默认,重跑 P4.1–P4.7 导出即可,合同与工具按层描述符实现,不硬编码 YOLOv8n。
- 三类(含落叶)训练与学生模型(ReLU)训练不在 P4 内;P4 产物须保证换权重/换网络时只需重跑导出与向量生成。
- 数据边界:校准只用 train 394 张的冻结子集;109 张共同开发图只做最终精度评估,不用来调 scale;16 张 test 继续不推理。

## 3 节点拆分(按序执行,每节点独立验收)

### P4.0 量化合同 v1 冻结 → `docs/定点格式说明.md` + `configs/quantization_contract.json`

把实现架构 §5 的合同具体化并给版本号,至少冻结:RGB 通道顺序;输入归一化与 int8 表达(建议 x∈[0,1] 映射 0..127,sx=1/127,零点 0,写明非对称浪费半量程的取舍);布局 NHWC(主存)、OIHW(权重)、尾通道补零;Conv/BN 折叠顺序(先 fold BN 再量化权重);偏置 int32、尺度 sx×sw[o];权重 per-output-channel int8、激活 per-layer(张量级)int8;乘子/移位:sy 的逆用 32 位乘子 + 移位近似,右移采用**明确定义的最近舍入**(建议:先加 2^(shift-1) 再算术右移,负数同规则,合同内给证明性示例);饱和到 int8;ReLU/SiLU/MaxPool/Upsample/Concat 在整数域的逐位定义;累加上界校核公式(K²×Cin×max|qx|×max|qw|+|qb|)与不满足时的处理。
验收:任何人按文档能独立推导任一层的定点输出规则;合同有版本号与哈希。

### P4.1 BN 折叠与导出器 → `training/export/`

从 checkpoint 读出网络,冻结顺序执行 Conv+BN 折叠(eps 处理写明),生成模型包:`model_id`、格式版本、逐层描述符(类型、输入/输出尺寸、通道、stride、padding、量化表、乘子/移位)、int8 权重、校验值,存 `training/export/`。**同步产出算子分派表**(每个模块 → PL-v1:3×3/1×1 conv s1/s2、ReLU、重量化、候选池化;PS-整数:SiLU-LUT、MaxPool、Upsample、Concat/Split;PS-浮点:DFL/softmax/decode/NMS)。
验收:导出可重复(同输入同哈希);FP32 折叠前后模型在抽样图像上的输出最大偏差记录在案(折叠不应改变推理结果);分派表无"未分类"项。

### P4.2 PTQ 校准与逐层误差 → `experiments/p4_ptq/`

校准集冻结子集(建议 train 内固定 seed 抽 64 张,种子写死);前向收集每层激活直方图 → 冻结 scale 规则(默认对称 max,可选 99.9% 分位限幅,选定后写回合同版本);统计每层:权重/激活量化前后误差(L2、余弦、最大绝对误差)、饱和比例;报告首层与 detect 头输入的特别处理。
验收:每层 scale 可由文档规则 + 校准数据复现;逐层误差与饱和比例成表;校准图像清单与哈希入档。

### P4.3 Python 整数参考 → `reference/python/`

逐层 int8 计算:int32 累加、乘子/移位重量化、SiLU-LUT、MaxPool、Upsample、Concat、尾通道补零;输出可逐层导出 npy。**不做任何浮点捷径**(重量化不允许 `float` 乘法;SiLU 查表索引即整数输入)。
验收:与 P4.2 的 FP32 逐层输出对比误差成表;自身在重复运行下逐位一致;单帧 128 输入可运行。

### P4.4 C 整数参考 → `reference/c/`

按合同文档独立实现(不 import/复用 Python 代码,只共享模型包与合同),C11,gcc 13.2 编译命令固定并写入 README;stdin/文件读模型包与输入,输出逐层二进制。
验收:与 Python 参考在全部 golden vectors 上逐位一致;编译无警告(记录所用 `-Wall -Wextra` 输出)。

### P4.5 Golden vectors → `tests/golden/`

生成器脚本 + 六类向量:正常随机、边界(int8 极值、累加上界附近)、负数(舍入方向)、饱和(乘子溢出路径)、尾通道(非 4/8 倍数通道)、真实图像端到端(≥8 张,含负样本与检出图)。每向量含输入、逐层期望输出、模型包哈希、合同版本、生成脚本哈希。
验收:向量覆盖分派表中每类算子至少一次;附 README 说明每个向量针对的规则分支。

### P4.6 资源与带宽报告 → `experiments/p4_资源与带宽报告.md`

按层:MAC 数、int8 权重 KB、特征图 KB;NHWC tile 假设下的 DDR 读写流量(上界 = 无片上复用,下界 = 理想行缓存);累加位宽校核结果表;按 Zynq-7010/7020 DSP 数粗估并行度上限与频率假设,全部标明"估算"。
验收:每层数字可由描述符重算核对;报告不含任何实测上板声明。

### P4.7 PTQ 精度评估与 QAT 决策门 → `experiments/P4_P4.7_量化评估简报.md`

109 张开发图:FP32 vs 整数参考,库内 mAP50/mAP50:95/分AP + 固定工作点(conf 0.25、NMS 0.45、匹配 IoU 0.5)TP/FP/FN 与负样本图片误检,与 R1.3 S0 同口径;小目标分组仍按 128 参考尺度。
决策门:mAP50 下降 ≤3pp 且关键类(明火)召回损失可解释 → P4 关闭,建议进入 P5;否则提出 QAT 计划草案(需训练循环改造,另立文档)供用户决策,**不自动启动 QAT**。

## 5 风险与未决项

1. **SiLU 定点化是最大不确定项**:默认方案为逐层 LUT(输入 int8 → 表项按本层输出 scale 量化),LUT 生成规则在 P4.0 冻结;PL-v1 不支持 SiLU,学生模型(ReLU)替换属于后续训练决策——若用户希望 P4 内直接训练 ReLU 学生模型,须先扩计划,不在本计划默认范围。
2. **int32 累加不默认安全**:逐层按合同公式校核上界;若某层超界,记录并评估该层提升位宽或限幅,合同预留"逐层例外"字段。
3. 校准集小(64 张)可能使激活 scale 偏;P4.2 必须同时报告 min/max 与分位两种结果,选择依据写入文档,不得只报好看的一种。
4. gcc 环境是本机 MinGW,C 参考代码规范限制为可交叉编译子集(无文件系统依赖的纯计算核心与 I/O 薄层分离)。
5. DFL/decode/NMS 归 PS 浮点:整数合同覆盖到 detect 头最后一层卷积原始输出为止,边界在合同中写明,避免"整网整数"的误称。
6. 量化误差与训练随机性无关(不重训),但 PTQ 评估仍用与 R1.3 相同的固定工作点口径,防口径漂移。
