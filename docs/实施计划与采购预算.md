# 实施计划与采购预算

版本：v0.1，2026-09-26。硬件尚未采购，预算上限人民币 1000 元。以下金额是采购控制额度，并非实时挂牌或成交报价；公开搜索未获得足够可靠的同配置二手报价。

该分配以已有可用电脑、无需额外购买仪器为前提，不能保证每项都能按额度买到。如果红外测温或开发板超额，先争取学校借用和已有设备，重新核算后再申报。

Zynq 系列将处理器和 FPGA 集成在同一器件，符合拟定 PS+PL 分工。[AMD 官方产品说明](https://www.amd.com/zh-cn/products/adaptive-socs-and-fpgas/soc/zynq-7000.html) 7010/7020 是询价候选，不是已证明能部署当前模型的选型结论；综合必须选择准确芯片型号。

## 2 二手板卡的准入条件

采购前取得：板卡品牌与版本、完整芯片丝印、DDR 容量、原理图、引脚约束、启动示例、下载器信息，以及卖家的开机/DDR 测试记录。确认所售物品是可独立供电调试的完整板，或把核心板所需底板计入总价。

确认摄像头路径：板上 USB Host 是否具备 PHY、供电与驱动；否则是否有可用摄像头接口或以太网。不能只按芯片手册推断板卡实际引出的接口。模拟传感器接 ADC 前核对电压，不能把 5V 模拟量直接接入不兼容的 FPGA 管脚。

矿板、拆机核心板仅作为有完整资料和验证条件时的备选，节省的价格可能转化为启动、供电和接口适配工作。缺少关键资料时不作为主方案。

若 450 元内找不到合适完整板：优先借学校板卡，同时完成软件和 RTL 仿真；再评估电脑提供图像、FPGA 执行核心卷积的辅助方案。如果必须借板才能上板，应在采购申报和计划中明确依赖，不能把仿真当作上板完成。

## 3 阶段推进与退出条件

| 阶段 | 主要工作 | 进入下一阶段的条件 |
|---|---|---|
| P0 需求和资源确认 | 现有电脑配置、可借板卡、候选板报价、三类标注规范与 ROI 定义 | 1000 元清单可落地；形成候选板能力表 |
| P1 软件最小闭环 | 视频输入、三类检测基线、传感日志回放、四级风险和事件日志 | 一组带真值的场景可重复回放并解释每次触发 |
| P2 量化与整数合同 | 小模型训练、PTQ/QAT 比较、BN 折叠、导出和参考计算 | 各层算子受支持；量化精度可接受；资源与流量预算可解释 |
| P3 单卷积硬件 | MAC、缓存、3×3/1×1、激活、重量化和测试台 | 正常与边界向量逐位一致，目标器件综合可行 |
| P4 上板和网络调度 | 先单层 DMA 对拍，再逐层串联，最后优化缓存 | 硬件读回一致；真实实现时序通过；端到端实测且标明 PS/PL 范围 |
| P5 传感和报警联调 | 真实采样、标定、时间对齐、健康状态、蜂鸣器和查询页 | 正常/关注/预警/报警及故障场景均可演示 |
| P6 对比实验与论文 | 三类模型指标、三种执行方式、单模态/融合、稳定性 | 数据可追溯到模型、配置、数据划分、位流和运行日志 |

采购不阻塞 P1 和 P2 的前期工作，正式大规模训练应在初步算子综合后进行，避免模型训练完成才发现硬件不支持。板卡到货后尽早验证 JTAG、DDR、GPIO 和传输链路。

## 4 与现有论文进度衔接

2026 年 9–10 月：完成 P0、架构、询价和软件闭环雏形。11–12 月：完成数据集与 P1，并尽早做小 MAC 综合实验。2027 年 1–2 月：完成 P2/P3，同时准备驱动和板级测试。3 月：完成 P4/P5。4 月：完成 P6、答辩演示和材料归档。5 月：依据实测数据修改论文。

这与任务书时间表保持一致，但提前做少量硬件验证，用于尽早排除资源和接口风险。

## 5 实施时的工作分工

助手可在工作区完成需求与接口文档、训练和导出脚本、整数参考、RTL 与测试台、构建脚本、融合逻辑、简单界面及结果分析；需要结合实际运行日志迭代，不能提前承诺模型精度或时序收敛。

用户提供采购确认、实际板卡型号、现场连接与上电、校园样本及实验真值，并运行当前环境无法访问的仪器和硬件步骤。训练算力尚未确认，后续先检查现有电脑或学校资源，避免把长期 GPU 租赁成本隐含排除在预算外。

## 6 首批具体任务

1. 建立三类标注规范和校园场景采集清单，固定 ROI 与困难负样本定义。
2. 整理候选板及现有电脑能力，选取准确器件做小型 MAC 综合估算。
3. 实现可切换视频/回放输入的软件链路，先输出检测与风险事件 JSON。
4. 冻结最小模型算子集合与整数计算合同，再开始第一轮硬件友好训练。

每阶段保留未通过的结果和调整理由。最终论文围绕“落叶风险积累、多源融合、软硬件一致性、实际加速效果”组织证据，不能预先写成降低误报或提高速度已经得到验证。
