## 各节点结果

### R1.1 收益重复验证(新种子 128/320 配对)

- 新种子 seed=20260927 下同时训练 128 与 320 两臂,唯一配方差异为 imgsz;冻结 R1 工具未修改,新入口 `tools.run_r11_paired_experiment` 显式接收种子。

- FP 代价随种子波动:旧种子 30 → 48(+18),新种子 47 → 48(+1)。"320 必然大幅增加误检"不成立,但烟雾 ge16 有小幅回退(35 → 31)。
- 同尺寸种子波动很大(128 输入 FP 30 ↔ 47),小于该量级的差异不可作稳定结论;两个种子仍不构成统计稳定性。

- 简报:[P2_R1.1种子重复简报](../experiments/P2_R1.1种子重复简报.md);权重:128 臂 `67628a5a…`、320 臂 `7a84d1a8…`(best 轮次 34/47,指标匹配推断,见各 run 的 verification.json)。

## 当前结论与模型身份

- 默认模型与工作点不变:原 128 基线 `experiments/p2_expanded_train/fit/weights/best.pt`(`c93676b3…`),conf=0.25、NMS=0.45。
- R1 320 及新种子 320 均为软件研究候选;两个种子的配对证据支持"320 提升小目标与 mAP、代价随种子波动",但**是否晋升默认、是否用于 FPGA 输入重议,属于需要人工决策的节点**。
- 测试集 16 张继续未动;现实采集与硬件采购仍暂缓;P3 阈值未标定。

## 复现入口

- R1.1:`python -m tools.run_r11_paired_experiment --output experiments/新的唯一目录 --seed 新种子`(种子必须显式给出且不等于 20260926)。
- R1.2:`python -m tools.prepare_fp_review`(默认读 R1 冻结产物,输出到新目录)。
- R1.3:`python -m tools.run_r13_working_points --weights <候选.pt> --imgsz 320 --output 新目录`;方案网格固定于脚本,改网格须另立计划文档。
- P3 对接:`python -m tools.adapt_p2_fusion --run <推理目录> --timeline <清单> --output 新目录` 后 `python -m tools.verify_p3_bridge_320 --output 新目录`。
- 报告:`python -m tools.report_r11_experiment --run <run> --interrupted-run <失败run> --output 简报路径`。
