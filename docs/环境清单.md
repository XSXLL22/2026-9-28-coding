## 环境决策

当前系统 Python 3.14 不直接作为训练环境。后续建立项目虚拟环境时，应根据所选 PyTorch 和 Ultralytics 版本选择其官方支持的 Python 版本，并锁定依赖文件。P0 不安装依赖，因为模型框架版本尚未冻结。

Icarus Verilog 可以先支持基础 Verilog 仿真；最终综合、实现和上板仍需要与所购芯片匹配的 Vivado/Vitis。
