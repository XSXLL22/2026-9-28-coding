## P3 首版边界

先做单节点的确定性离线回放：输入视觉证据与模拟传感器记录，输出风险变化和健康状态的 JSONL。无须硬件。模拟记录必须带 `origin=simulation`，不作为真实传感器或火灾实验数据。

输入校验、时间对齐、状态更新和事件记录分开实现。暂不接蜂鸣器、网页、数据库或设备驱动。现有烟火模型只能用于验证接口，不能支撑报警可靠性的结论。

## 输入合同草案 v0.1

所有输入共有 `schema_version`、`node_id`、`session_id`、`record_id`、`origin`、`sample_time_ms`、`available_time_ms`、`clock_id`、`valid`、`invalid_reason`。同一回放会话的时间单位为毫秒，从约定起点开始；墙钟时间可另存，不能参与持续时间判断。

- `sample_time_ms`：采样或视频帧所属时刻。
- `available_time_ms`：该记录实际可被融合模块使用的时刻，用于表达推理或传输延迟；不能早于采样时刻。
- `clock_id`：明确共同时间轴，未完成时钟映射的不同节点/会话不能直接融合。
- `valid=false`：该记录不能用于风险证据；值缺失用 null，不能改成 0。
- `record_id`：会话内唯一，重复记录不重复累计持续时间。

### 传感器记录

额外字段：`sensor_id`、`sensor_type`、`value`、`unit`、`calibration_status`、`health`。传感器类型分为环境温度、相对湿度、烟雾相对信号、火焰模块信号、红外表面温度。环境温度与表面温度不互换；未标定烟雾信号不能填写 ppm。数据年龄由融合时刻减采样时刻计算，不信任输入预填的年龄。

### 视觉记录与 P2 对接

保留 P2 的 `frame_id`、`model_sha256`、`detections`、原图尺寸、项目类别、原图框、置信度及 `roi_box_area_fraction`。另携带本次 `run.json`、配置快照的引用或哈希、支持类别和 ROI 标定状态。

适配器从 P2 `source_timestamp_ms` 与显式的会话时间映射取得采样时间。图片目录时间为 null 时，仅能作为无时序单图证据；需要时序模拟必须另建有明确时间的回放清单，并标记模拟来源，不能偷偷按帧号补时间。现有推理耗时不能直接当作采样时刻。

当前模型不支持 leaf_pile，空检测不表示不存在落叶。框与 ROI 的相交比例不是落叶覆盖 ROI 的面积比例，也不是物理距离；后续落叶规则若需要覆盖率，必须另算并明确重叠框去重方式。

## 时间与健康约束

融合在显式的回放时刻 tick 更新，包括没有新记录的时刻，以便发现停帧与过期。只消费 `available_time_ms <= tick` 的记录，不使用未来信息。持续时间依据采样时间及允许的观测间隔判定，重复旧记录不能延长证据；最大数据年龄、允许间隔和乱序策略尚待配置与测试。

风险等级保持 NORMAL、ATTENTION、WARNING、ALARM；另设 `risk_assessment_valid`，初始化没有证据时风险值为 null、评估无效。健康状态独立表示 OK、DEGRADED、UNAVAILABLE，并带原因。缺少必要数据时不产生“已确认正常”的新结论；已知风险可保留，但必须标记证据过期或评估受限。哪些模态属于必要数据，后续按启用的规则显式配置。

## 状态转换方向（尚未编码）

| 方向 | 候选证据 | 待验证内容 |
|---|---|---|
| → ATTENTION | 持续弱异常，或 ROI 内持续落叶证据 | 类别可用性、持续时间和观测间隔 |
| → WARNING | 持续烟雾、较强温升，或时空对应的组合异常 | 时间窗口、温升定义、证据独立性 |
| → ALARM | 经验证的强单源证据，或对应的多源强证据 | 强单源可直接升级；不得因其他模态缺失而一律禁止升级 |
| → 较低级别 | 新鲜有效数据持续满足恢复条件 | 恢复阈值与持续时间；不能因断流自动解除 |

阈值暂不填写生产数值。将来的演示配置须注明 simulation_only，持续时间、最大年龄、升级/恢复阈值均集中保存且有版本。上述规则方向不是已实现或经标定的报警规则。

输出事件至少包含 `event_id`、会话/节点、评估时刻、前后风险级别、`risk_assessment_valid`、健康状态、`reason_codes`、证据记录 ID、数据年龄、模型/数据/配置/规则版本。健康变化与风险变化都要可追溯；同一输入与配置应产生相同事件序列和稳定事件 ID。
