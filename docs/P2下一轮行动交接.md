## 4. 之后的训练对照：按顺序控制变量

所有实验开始前先写配置和比较对象；不覆盖 `p2_expanded_train`，不在同一个目录通过反复运行混合不同实验。

| 实验 | 唯一主要变化 | 固定项及注意事项 |
|---|---|---|
| A1 | warmup_bias_lr：0.1 → 0.0 | 128、50 轮、相同原始权重/数据/种子、AdamW 与 lr0 不变；不是续训 |
| A2 | close_mosaic：0 → 10 | 采用哪个预热配方必须明确，控制组使用完全相同配方；另测 mosaic=0 要新建实验 |
| R1 | 匹配训练/评估尺寸：128 → 320 | 用同一已选训练配方；若 batch 或环境被迫改变，补匹配控制并披露，不声称纯单变量 |

首轮每个候选只跑一个固定种子筛查；有希望的方案再补种子验证稳定性。训练前记录预计资源，超过可用资源时停止并说明，不能自动大规模扫参。当前约 463 秒是旧 CPU 训练入口总耗时，包含审核和评估，也受并行活动影响，不能直接据此承诺 320/640 的耗时。

若三者均无收益，下一步优先检查数据覆盖、标注一致性和候选定位，不把更换 YOLO 大版本当作必然解法。若 R1 改善明显，再推进固定切片或带上下文 ROI 的训练/推理对照。两条分支的具体约束见调研文档。

## 6. 数据和评估的交接红线

- 109 张已用于挑模型和研究失败原因，只能称开发验证集。不得将其中失败图或近重复样本加入训练后继续称公平同集比较。
- 更换标注必须形成新版本，说明客观理由，让比较双方重新评估；不得按模型预测修改真值以抬高分数。
- 外部预训练权重必须核实训练来源。来源可能包含当前验证集时，其高分不能作为独立泛化证据。
- 切片前划分来源组；验证时不能按真实框裁剪，不可静默排除 ROI 外漏检。全图与 ROI 内成绩应分开且分母明确。
- 小目标对照保持同一目标集合，匹配 IoU 不变。减少阈值带来的误报增加必须同时报告。
- 没有连续视频就不报告事件召回、发现延迟或每小时误报；没有板卡测量就不报告 FPGA FPS、功耗或资源占用。
